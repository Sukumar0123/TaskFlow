# TaskFlow - Daily Planner & Diary

A simple frontend-only productivity app built with HTML, CSS, and JavaScript.

## Features
- Add, edit, delete daily tasks
- Created date, updated date, completed date
- Task notes
- Daily diary entry
- Mood tracker
- Diary and task history
- Search and filters
- Progress tracker
- Dark/light mode
- LocalStorage persistence
- Vercel/Netlify ready

## Run
Open `index.html` in your browser.

## Deploy on Vercel
Upload this folder to GitHub, then import it in Vercel as a static project.
